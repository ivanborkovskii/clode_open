# Корпоративный сайт: внедрение Битрикс24 и amoCRM

Этап 1: дизайн-система и главная страница.
Внутренние страницы не разрабатываются — структура под них подготовлена.

## Стек

PHP 8.1+, MySQL, HTML, CSS, JavaScript. Без фреймворков и сборщиков:
статика отдаётся как есть, зависимостей и шага сборки нет.

Раздел статей рассчитан на тысячи материалов, поэтому страницы формируются
на сервере из базы: публикация новой статьи не требует пересборки и выкладки сайта.

## Запуск

```bash
php -S 127.0.0.1:8000 -t public
```

Открыть http://127.0.0.1:8000

Боевой сервер: корень сайта — каталог `public`, остальное лежит выше и напрямую недоступно.

### Настройки

Задаются переменными окружения, значения по умолчанию — в `config/app.php`:

| Переменная | Назначение |
|---|---|
| `APP_URL` | Адрес сайта. Подставляется в canonical, Open Graph и sitemap |
| `APP_DEBUG` | `false` на боевом сервере |
| `DB_HOST`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD` | Доступ к базе (нужен для статей) |

База разворачивается из `database/schema.sql`. Для главной страницы база не нужна —
соединение открывается только при обращении к ней.

## Структура

```
app/
  Core/          Router, View, Validator, Csrf, Database, Autoloader
  Controllers/   HomeController, LeadController, SitemapController
  Views/
    layouts/     Общий макет: мета-теги, подключение стилей
    partials/    Шапка, подвал
    sections/    Блоки страницы — переиспользуются на внутренних страницах
    pages/       Сборка страницы из секций
config/
  app.php        Настройки и данные компании
  routes.php     Маршруты
  content/       Тексты страниц отдельно от вёрстки
database/
  schema.sql     Таблицы статей, рубрик и заявок
public/          Корень сайта: index.php, статика, robots.txt
storage/logs/    Заявки с форм (до подключения интеграции)
```

### Как добавить страницу

1. Маршрут в `config/routes.php` (заготовки уже есть в комментариях).
2. Метод контроллера — задать `seo` и передать данные в шаблон.
3. Шаблон в `app/Views/pages/` — собрать из готовых секций.
4. Добавить путь в `SitemapController::pages()`.

## Дизайн-система

Токены — в начале `public/assets/css/app.css`.

**Цвет.** Тёмно-синий `#071739` — фон первого экрана, тёмных секций, шапки и подвала.
Акцентный синий `#1e96f0` — кнопки, ссылки, маркеры. Белый и холодный светлый `#f2f2f7`
чередуются как фон светлых секций. Текст: `#071739` основной, `#56607a` вторичный.
Больше цветов не вводится.

**Типографика.** Manrope Variable, локально, два подмножества (кириллица + латиница) —
39 КБ на все начертания. Размеры заданы через `clamp()` и масштабируются плавно,
поэтому отдельных мобильных размеров не требуется.

**Форма.** Скругления 2–3 px. Разделители — линии, а не рамки карточек.
Секции разделяются фоном, а не тенями.

## SEO

- Уникальные `title` и `description` для каждой страницы (задаются в контроллере)
- Один `H1`, дальше последовательные `H2` → `H3`
- `canonical`, Open Graph, микроразметка ProfessionalService
- `/sitemap.xml` — индекс карт. Разбит на файлы сразу: лимит поисковых систем —
  50 000 URL на файл, при тысячах статей одного файла не хватит
- `/robots.txt` — заменить домен при выкладке
- URL без завершающего слэша; `/uslugi` и `/uslugi/` ведут на один адрес

## Производительность

Главная страница: 7 запросов, ~148 КБ без сжатия, растровых изображений нет —
схема на первом экране и иконки сделаны в SVG. На сервере с gzip объём примерно вчетверо меньше.

## Формы

Заявка отправляется через fetch без перезагрузки страницы; без JavaScript работает
обычной отправкой. Проверка данных выполняется на сервере в любом случае.
Защита: CSRF-токен и скрытое поле-ловушка для ботов.

Сейчас заявки пишутся в `storage/logs/leads.log`. Для подключения Битрикс24, amoCRM
или почты нужно изменить один метод — `LeadController::save()`.
